Help

Form vs JSON: Use the form for common fields, or edit JSON directly for complex structures.

Required fields: ID is always required. Other requirements depend on the data type.

{% if data_type == 'skills' %}

Skills: Effect objects and level modifiers can be complex - use JSON editor for these.

{% elif data_type == 'monsters' %}

Monsters: Use the form fields to set abilities with chances, immunities, and resistances.

Abilities: Enter decimal chances (0.1-1.0). They'll be normalized to sum to 1.0 automatically.

Resistances: Negative values = resistance, positive = vulnerability. Example: -50 = 50% resistance.

{% elif data_type == 'monster_abilities' %}

Monster Abilities: Define abilities used by monsters in combat.

Base Power: Damage/effect strength (typically 50-200 for most abilities).

Type: Physical (uses attack), Magical (uses magic attack), or Support (no damage).

Target: Who the ability affects - single/all enemies or allies, or self.

{% elif data_type == 'items' %}

Items: Configure basic item properties including stats, type, and equipment slot.

Jobs: Specify which jobs can use this item. Leave empty for universal items.

Requirements: Use the JSON editor to set attribute requirements (e.g., {"STR": 10}).

{% elif data_type == 'jobs' %}

Jobs: Most fields are available in the form. Use JSON for complex properties like passive abilities.

Attribute Modifiers: Only non-zero values are saved. Negative values reduce attributes.

Requirements: Only jobs with level requirements need to be specified.

{% elif data_type == 'quests' %}

Quests: Define the type, giver, status, level, difficulty, and seed for a quest.

Objective: Set the target ID/name, count, and location for a quest.

Rewards: Define gold and reputation rewards for a quest.

{% elif data_type == 'smith_recipes' %}

Smith Recipes: Define the result item, category, gold cost, and materials required for a recipe.

Materials: Add and manage materials required for a recipe.

{% elif data_type == 'unique_items' %}

Unique Items: Create powerful items with special effects and restrictions.

Effects: Add multiple unique effects with different types (damage modifiers, resistances, skill grants, etc.).

Requirements: Set attribute requirements and job restrictions to control who can use the item.

{% elif data_type == 'set_items' %}

Set Items: Create items that belong to a set and provide bonuses when worn together.

Set Info: Specify the set name, piece number, and total pieces in the set.

Bonuses: Set bonuses are defined separately in the Set Bonuses section.

{% elif data_type == 'set_bonuses' %}

Set Bonuses: Define bonuses that activate when multiple set pieces are equipped.

Piece Count: Each bonus specifies how many pieces are needed to activate.

Bonus Types: Resistance, immunity, damage modifiers, skill grants, and stat boosts.

{% endif %}
